# Arquivos originais da INOVEK

As imagens do chat não são entregues como arquivos ao projeto. Salve aqui os arquivos originais enviados pelo cliente com os nomes abaixo (extensões aceitas: `.png`, `.jpg`, `.jpeg`, `.webp`; para o logo, também `.svg`). O build passa a usá-los automaticamente e os incorpora ao catálogo.

- `logo-inovek.png` (ou outra extensão aceita)
- `01-sistema-fixacao.png`
- `02-espelho-movel.png`
- `03-espelho-led-premium.png`
- `04-espelho-decorativo.png`
- `05-espelho-iluminado.png`
- `06-espelho-barbearia.png`
- `07-espelho-profissional.png`

Enquanto algum arquivo não estiver aqui, a respectiva imagem ilustrativa da prévia será usada. Nunca renomeie o arquivo com dois formatos ao mesmo tempo (por exemplo, `.png.jpg`).
